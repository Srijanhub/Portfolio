## 🚀 How to Run Locally

No external build tools, package managers, or dependencies are required.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Srijanhub/Portfolio.git
   cd Portfolio
   ```
2. **Open in Browser**:
   - Double-click `index.html` to open it in Chrome, Safari, Firefox, or Edge.
   - Or launch using VS Code Live Server extension.
